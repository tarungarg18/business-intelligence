# --- Evidence Engine (retrieval) ---
# No torch, no ONNX runtime, no local model weights.
#
# Embeddings come from an API (Gemini primary, any embedding-capable
# OpenAI-compatible endpoint as fallback) over plain REST, with results cached
# to disk so the demo runs offline after the first build. Generation also has
# OpenRouter/Hugging Face fallbacks. With no key at all the system falls back
# to TF-IDF + SVD via scikit-learn, which is already a dependency.
#
# sentence-transformers + ChromaDB are the plan's neural retrieval stack. They
# are OPTIONAL: they pull in ~2 GB of torch for a corpus of a few hundred
# chunks. When installed, the Evidence Engine uses the BGE/MiniLM encoder and a
# persistent Chroma collection; when absent, it degrades to a deterministic
# hashing/lexical floor so the demo still runs offline and reproducibly.
#
#   pip install "sentence-transformers>=2.2" "chromadb>=0.4"
#
